### Changed

## [1.0.0] — 2026-08-24

**1.0** — the first code-module ships stable.

### Changed
- Version is now `1.0.0` (was `0.1.0-beta`). No behaviour change; Tiger itself reached 1.0 and the
  module line follows.

### Note
Code snippets run **in-process** on your server. Install ≠ activate: snippets arrive inactive, and you
read the source before activating. Activation is superadmin-only.
